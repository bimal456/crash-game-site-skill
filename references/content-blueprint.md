# Content blueprint

Placeholders: `{{GAME}}`, `{{SEQUEL}}`, `{{PROVIDER}}`, `{{GEO}}`, `{{REGULATOR}}`, `{{HELPLINE}}`, `{{YEAR}}`. Write every edition in its native language. Voice rules in `voice-and-positioning.md` apply to every line below.

## Page skeleton (generated)
```
header: logo (link home) + site name + descriptor + primary nav (aria-current)
breadcrumb (plain, no box)
opening: eyebrow + H1 + lead + byline "Updated <date> · Sources"  (no disclosure line: owner rule, round 4)
article (full width, NO table of contents): sections (H2, H3), tables, CTA boxes, figures, FAQ, sources
related pages cards
footer: nav + cookie link + editions switcher + footer_about + footer_rg (helpline) + footer_legal
```

## Home (2700-3000 words) section order
1. What is {{GAME}} (cash-out mechanic, crash family, {{PROVIDER}})
2. Original vs clones (same-name apps, lookalikes; verify {{PROVIDER}} in the info panel)
3. How {{GAME}} works (steps) + difficulty table + gameplay figure (links to demo)
4. Spec sheet table
5. Demo teaser (link) then CTA
6. Does it really pay / scam / legit (longest money section)
7. Legal status in {{GEO}} ({{REGULATOR}}, licensed vs offshore, provider restrictions)
8. RTP, volatility, payouts
9. Where to play in {{GEO}} (how to pick an operator, licence check) then CTA2
10. Operator availability table, or a licence-check table where the game is not legal/restricted
11. How to register and start (steps box)
12. Bonus / code / free spins / no deposit (hypothetical rollover example) then CTA3
13. App / download / APK warning
14. {{SEQUEL}} teaser + mascot figure (links to sequel page)
15. {{GAME}} vs other crash games (table)
16. Tricks and strategy (honest, habits not tricks)
17. **{{GAME}} pros and cons** (pros-cons box; "what players say" allowed; NO review/verdict)
18. Responsible gambling (`id="responsible-gambling"`, plain, helpline, link)
19. FAQ (10-12, answers 30-70 words)
20. Sources

Only 5-6 of these sections carry designed blocks (callouts, cards, steps, pros-cons), varied and spread out. Tables are not counted. No "Conclusion" section.

## Demo (1500-1800)
what the demo is -> how to play free -> what you can test (difficulty table) -> mobile -> what to test before real money -> demo vs real money table -> sequel demo -> fake demo sites warning -> moving to real money (CTA) -> FAQ (6-8) -> sources. Gameplay figure near the top.

## Sequel (1500-1800)
what it is -> differences table -> how it works -> spec table -> does it pay / legit -> demo (CTA2) -> app -> where to play (CTA) -> bonus and registration -> strategy -> pros and cons (no review wording) -> FAQ (6-8) -> sources. Sequel figure near the top.

## Payments + tax (1500-1800)
methods overview + table -> how to deposit -> withdrawals and timing -> KYC -> safe payments / red flags -> bonus rollover -> tax in {{GEO}} (not tax advice) -> CTA -> FAQ (6-8) -> sources.

## About (900-1300) "About <domain>"
What the site covers (editions, pages) -> `#method` "How the pages are kept up to date" (provider page and regulators as sources, specs checked against the in-game info panel, pages re-dated) -> `#sources-we-use` -> how the site makes money (promotional links, nofollow sponsored, facts unchanged) -> corrections via contact. No team, no review, no independence.

## Contact (400-700)
`contact@<domain>` (mailto), what to write about, what the site cannot do (no casino account support; regulator complaint route per geo), helpline.

## Responsible gambling (800-1200), plain page
Harm message, warning signs, limits, tools, self-exclusion scheme, helplines with numbers, family help, minors (no "18+" wording). No designed blocks.

## Privacy / Cookie / Terms
Static site, no cookies, no analytics, no forms; host/CDN logs; affiliate links lead to third-party sites with their own policies; terms: content is not legal/financial/tax advice, no guaranteed winnings, check local law, trademarks of {{PROVIDER}}, promotional-link disclosure. No company name or address invented. No "independent / not affiliated" sentences.

## Formatting
Prose 70%+; tables for difficulty, specs, operators/licence checks, payments, crash-game comparison; FAQ as details/summary mirrored in FAQPage schema; CTA boxes and callouts with CSS hover; short plain-tone lead (~8%) then professional tone.
